About piapps.dev

The landing page for self-hosted apps running on a Raspberry Pi 5 homelab. Built as a fast, lightweight index to showcase homelab dashboards, developer utilities, and browser sandboxes.

Tech Stack
HTML, CSS and vanilla JavaScript (no framework, no build); served by nginx on a Raspberry Pi 5; Cloudflare in front; strict Content-Security-Policy.
